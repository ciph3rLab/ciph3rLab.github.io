# CiPH3R-Lab Website

This repository hosts the official website for **CiPH3R-Lab (Cybersecurity, Privacy, and Human-centric Research Laboratory)** at Texas A&M University–San Antonio.

Website: https://ciph3rlab.github.io/

## About CiPH3R-Lab

CiPH3R-Lab conducts research at the intersection of:

- Offensive and Defensive Cybersecurity Techniques
- Privacy-preserving and trustworthy AI
- Adversarial machine learning and AI red teaming
- Security of critical and cyber-physical infrastructure

The lab develops secure and resilient AI systems with strong real-world impact.

## Website Technology

The website is built using:

- Jekyll
- Academic Pages template
- GitHub Pages hosting

Original template: https://academicpages.github.io

## Repository Structure
- _pages/ → Website pages
- _publications/ → Publication entries
- _posts/ → News updates
- _includes/ → Layout components
- assets/ → Images and site resources
- files/ → PDFs and supplementary files


## Running Locally

To run the website locally:
bundle install
bundle exec jekyll serve

Then open:
http://localhost:4000
